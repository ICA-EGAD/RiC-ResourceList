Records in Contexts: An Introduction --- Understanding the New International Standard for Archival Description

    (Records in Contexts 入門 --- アーカイブズ記述の新しい国際標準を理解する)
  • Tetsuji Kuboyama (https://tk.cc.gakushuin.ac.jp/en/)
    • 2026-08-23 (Japanese edition v1.4.4)
    • 2026-08-23 (English edition v1.0)

    • A free textbook that introduces Records in Contexts to readers meeting it for the first time. The primary sources are written for implementers; this book is written for the first encounter, and works throughout from RiC-FAD 1.0, RiC-CM 1.0, RiC-O 1.1 and RiC-AG 0.1 — the text, the OWL source, the official documentation, the official crosswalks and the sample data.

      It covers what the move from multilevel to multidimensional description means, how to read entities, attributes and relations, an introduction to RDF, Turtle, OWL, description logic and SPARQL, six situations in which inference does useful work, the steps of converting from EAD, and how much computer science the work requires. Each chapter ends with exercises. The appendices hold reference tables and a glossary of words that shift meaning between archival science, library science and computer science.

      Sample data accompanies the book and is published separately: four Turtle datasets, the fourteen SPARQL queries that appear in the text, SHACL shapes with data that violates them, and a script that checks every file against RiC-O. All of it is fictional and carries the same CC BY 4.0 licence, so it may be adapted for teaching.

      The Japanese edition came first, in July 2026. The English edition replaces the Japanese records, institutions and legislation used in the examples rather than translating them, so that they can be followed without knowledge of Japanese archival practice. (English)
